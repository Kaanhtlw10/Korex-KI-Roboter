# Was ist Korex der Roboter?
Korex der Roboter ist ein **KI-Integrierter** Roboter der Mittels einer Internet Verbindung Online Daten abrufen kann. Er trennt sich vom Schwesterprojekt Lorex indem er mit einem Handheld-Kontroller gesteuertert werden kann. Sie können Gespräche mit Korex starten, ihn Dinge abfragen oder ihn fahren. 

## Über Korex
Der Kontroller zu Korex wurde von uns selber entwickelt. Korex verwendet eine MIFA Antenne auf seinen Kontroller, um Signale auszuschicken. Bitte beachten Sie: von selbst wird Korex nicht ein Gespräch interagieren. Korex hat **nicht** die Funktion der Gesichtserkennung, also kann er nicht unterscheiden mit wem er redet.
