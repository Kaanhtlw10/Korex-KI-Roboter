# Was ist Korex der Roboter?
Korex ist ein KI-integrierter Roboter, der per Controller gesteuert wird,
Fotos und Videos aufnehmen kann und sich mit Menschen unterhalten kann.

## Funktionen

- **Fahren:** Korex wird über einen selbst entwickelten Controller gesteuert
  und fährt mit Batteriebetrieb.
- **Kamera:** Auf Anweisung nimmt Korex Bilder und Videos auf.
- **KI-Dialog:** Man kann mit Korex sprechen. Er antwortet, startet von sich
  aus aber keine Gespräche.
- **Display:** Auf dem Bildschirm an seinem Körper wird sein Gesicht gezeigt.
  Außerdem zeigt er dort Bilder, die zu einer gestellten Frage passen.

## Controller

Der Controller wurde im Projekt selbst entwickelt. Als Antenne dient eine
MIFA (Meandered Inverted-F Antenna), eine PCB-Antenne, die direkt auf der
Platine sitzt.

## Stromversorgung

Korex läuft mit einer Batterie.
